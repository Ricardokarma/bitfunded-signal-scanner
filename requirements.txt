# Bitfunded Signal Scanner Pro

A stronger, more disciplined crypto scanner for Bitfunded-style challenges.

## Overview

This app scans active USDT futures markets, ranks the strongest Long and Short setups, and helps limit emotional overtrading. It is designed to support manual execution only.

## Included features

- automatic scan of active futures pairs
- 15m + 1h multi-timeframe confirmation
- EMA, RSI, MACD, ADX, ATR, and volume checks
- directional signal scoring from 0 to 100
- confidence and estimated win-rate output
- BTC dominance context
- funding and open-interest context
- manual trade journal
- auto-learning from journal results for better future suggestions
- challenge risk controls and execution checklist

## Local setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## How the learning works

The app reads your saved trades from `trades_journal.csv` and analyzes:
- average results by direction (LONG / SHORT)
- average results by mode (Scalp / Swing / Challenge)
- symbol-specific historical performance

It then adjusts the scanner’s score and ranking to favor setups that historically perform better in your trading behavior.

## Important note

This app is for educational and decision-support purposes only. It does not guarantee profit and does not place trades automatically.
